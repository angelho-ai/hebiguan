# Google Sheet 表單串接（約 5 分鐘）

## 步驟

1. 開一個新的 Google 試算表：<https://sheets.new>，命名例如「何必館看屋預約」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡的預設內容，把本資料夾 `Code.gs` 的全部內容貼上，**儲存**（Ctrl/Cmd+S）。
   - 通知信預設寄到 `angel.ho.ai.pm@gmail.com`，要改或關閉請改檔案最上方的 `NOTIFY_EMAIL`。
4. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（一定要選這個，表單才送得進來）
   - 按「部署」，第一次會要求授權 → 選你的帳號 → 進階 → 前往（不安全）→ 允許。
5. 複製部署完成後給的 **網頁應用程式網址**（`https://script.google.com/macros/s/xxxx/exec`）。
6. 打開網站的 `index.html`，找到最上方 `CONFIG` 設定區，把網址貼進 `SCRIPT_URL` 的引號內：

   ```js
   SCRIPT_URL: "https://script.google.com/macros/s/xxxx/exec",
   ```

7. 完成！可先在瀏覽器直接打開該網址測試，看到「何必館表單後端運作中 ok」代表部署成功；
   再到網站上送出一筆測試預約，確認試算表出現新的一列、信箱收到通知。

## 注意

- 之後若修改 Code.gs，要再走一次 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，改動才會生效（網址不變）。
- 電話欄位前面加了 `'`，是為了避免 Google Sheet 把 0912… 開頭的 0 吃掉。
